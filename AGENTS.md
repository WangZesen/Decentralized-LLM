# Report presentation

For all reports comparing training schemes or topologies, order plots as
**sync → cmp → exp → ring** (synchronous → complete → exponential → ring).
Apply this order to panels, legends, categorical axes, correlation-matrix axes,
and interactive selectors. Preserve each method's color when changing its position.
Use the shared definitions in `scripts/report_style.py`.

For existing audited reports, make a presentation revision and retain the original
scientific artifacts and their provenance. The tuning-series renderer is
`scripts/render_tuning_reports.py`.
